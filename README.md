# Munawwar Foundation — React Frontend

React + Vite + Framer Motion + Lenis frontend for the Munawwar Foundation website.

## Important deployment notes

This is a React SPA using `BrowserRouter`. The included `vercel.json` and `public/_redirects` configure common SPA fallback behavior so routes such as `/get-involved` continue to work after navigation or refresh.

The Support Our Work buttons route to `/get-involved`. Donation/payment details are intentionally not invented and remain foundation-input placeholders until verified information is supplied.

The contact form is frontend-only until the Foundation confirms its preferred submission workflow.
