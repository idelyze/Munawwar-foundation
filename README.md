# Munawwar Foundation Website

Responsive React and Vite website for Munawwar Foundation.

## Run locally

```sh
npm install
npm run dev
```

## Build for deployment

```sh
npm run build
```

Vite writes the production site to `dist/`. The included routing configuration supports direct links and refreshes on site pages.

## Website content

- Page and programme content: `src/data/foundation.js`
- Images and public documents: `public/`
- Page layouts and styles: `src/pages/` and `src/styles/`
